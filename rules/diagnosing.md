# Before diagnosing

- Ask which site: `/sites/CRS` (SDG, live) or `/sites/ClarenceDMSTesting` (test). The GUIDs differ.
- Stale tab or old package first: check the installed version in Site Contents, and a string on screen that only the new build has.
- Power Automate config is NOT in source. Read the real export in `PowerAutomateFlowsSDG/*.zip` before advising on any flow.
