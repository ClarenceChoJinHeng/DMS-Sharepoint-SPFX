# Keep the Obsidian vault current

Vault: `C:\Users\clare\OneDrive - Trinergy\Documents\Obsidian\Personal-Obsidian\Trinergy-Notes\SDG-Claude-Config`

1. **Component note**: open `Components/<name>.md`.
   - New or changed rule → add or edit a bullet under "Firm logic" (short, plain words).
   - New trap → add it under "Gotchas".
   - New component → copy `component-note-template.md` from this skill folder, fill it in, and add a row to `Code Map.md`.
2. **Code tag**: if you added `// #code/<tag>` in the source:
   - Create `Code Notes/<tag>.md` with `tags: [code/<tag>]`: the rule, the reason, and what breaks.
   - Add a link to `Code Notes/_Index.md`.
3. **Open Items.md**: tick finished items, add what still needs a live test.
4. **New spec or plan** → `Specs/YYYY-MM-DD-<topic>.md` or `Plans/…`.
5. **General lesson** (SharePoint / Power Automate) → `Gotchas - SharePoint.md` or `Gotchas - Power Automate.md`.
6. Never append history to `CLAUDE.md` or the `rules/` files. They hold rules only.

Keep every note short: bullets, no essays.
